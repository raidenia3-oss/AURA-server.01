Esta bóveda de Obsidian contiene toda la documentación estructurada del ecosistema AURA/AME, diseñada para facilitar la gestión visual del enjambre mediante el grafo de conexiones.

```
├── 04_Canvas/

└── README.md
```

## 🔗 Enlaces Internos

Todos los documentos en esta bóveda utilizan enlaces internos en formato `[[Archivo]]` para que Obsidian genere automáticamente el grafo de conexiones.

## 📌 Cómo Usar esta Bóveda

1. **Instalar Obsidian**: Descarga e instala el software desde [obsidian.md](https://obsidian.md/).
2. **Abrir la Bóveda**: Abre esta carpeta con Obsidian.
3. **Explorar el Grafo**: Utiliza la función de grafo de Obsidian (Plugin "Graph View") para visualizar las conexiones entre los documentos.
