# Proyecto AURA

El proyecto AURA involucra una aplicación de servidor ubicada en `https://aura-server-01.vercel.app/chat`.

Existe una habilidad (`aura-core`) que se utiliza para realizar solicitudes POST a este servidor.

Más detalles podrían ser obtenidos al inspeccionar la habilidad `aura-core` o interactuar directamente con el servidor.
